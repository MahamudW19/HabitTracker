# Habit Tracker App

## Overview

Habit Tracker is an Android application designed to help users create, manage, and maintain habits while monitoring their progress over time.

The app was built using Kotlin and Android Studio with a focus on providing a simple way to manage daily habits and encourage consistency.

## Features

- Create new habits
- View and manage existing habits
- Mark habits as completed
- Edit and delete habits
- Daily reminders
- Progress tracking and statistics

## Technologies Used

- Kotlin
- Android Studio
- Room Database

## Purpose

I developed this project to strengthen my Android development skills and gain practical experience building a complete mobile application with Kotlin.

The project gave me experience implementing habit management, local data storage, reminders, and progress tracking within an Android application.

## Running the Project

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and install the required dependencies.
4. Run the application using an Android emulator or compatible Android device.
